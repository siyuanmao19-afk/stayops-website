# StayOps updates / StayOps 更新记录

## 2026-11-17

- **Tasks and Overview / 任务与概览：** Open counts now match the exact Tasks status filter. Overview cards open prefiltered task views, urgent unresolved tasks appear first, and property names are easier to read. / 待处理数量与任务筛选口径一致；概览卡片可跳转到对应筛选结果，紧急未解决任务优先显示，房源名称更醒目。
- **Analytics / 数据分析：** Statuses use distinct colors and priority order; nationality labels use each country's local language. / 任务状态按优先级与不同颜色呈现；国籍名称使用各国当地语言。
- **Activity Logs / 活动日志：** Added keyword, task, property, source, and date filters. / 新增关键词、任务、房源、来源和日期筛选。
- **Properties / 房源：** Optional real photo URLs are supported, while missing photos are labeled. Legacy Chinese task text is translated for the English interface. / 支持真实房源图片链接，缺图时明确标注；英文界面会翻译旧记录中的中文任务文本。
- **Brand / 品牌：** The logo has a light backing for readability on dark backgrounds. / Logo 增加浅色衬底，在深色背景上更清晰。

## 2026-11-07

- **Registration code / 注册邀请码：** New accounts now require a server-validated registration code; existing accounts and login behavior are unchanged. / 新账号必须输入由服务端验证的邀请码，已有账号和登录方式不变。

- **Login / 登录：** Added simple email registration and sign-in. Workspace data now requires an authenticated member. / 新增简易邮箱注册和登录，工作台数据需要登录后访问。
- **Task status / 任务状态：** Status changes update immediately and no longer flash back to the previous value. / 状态修改后立即显示，不再短暂跳回旧状态。
- **AI summaries / AI 摘要：** Summaries now use concise task phrases. / 摘要改为简短清晰的任务短语。
- **Homepage / 首页：** Added a bilingual update notice linked to GitHub history. / 新增中英双语更新提示，并链接 GitHub 更新记录。

## 2026-11-06

- **Procedure fallback / 规范补充：** When no verified procedure matches, AI prepares a relevant draft for staff review. / 没有匹配规范时，AI 会生成相关草稿供员工审核。
